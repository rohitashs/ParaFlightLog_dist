# Paragliding Flight Log — User Guide (for everyday use)

## What this is (purpose)

A simple Google Sheet that turns your IGC track files into a clean, searchable flight diary. You drop IGCs into a Drive folder (or add them manually) and the sheet:

- creates one row per flight (newest on top),
- fills in times, distances, altitudes, speeds,
- guesses launch/landing places and nearby PG sites,
- scores XC/triangle distances and points,
- analyzes your flying by mode (Thermal / Soar / Glide / Sink),
- keeps your typical gear selected so logging stays quick.

---

## What it can do (features)

- **Automatic import**
    - Watches a Drive folder for new files (`.igc/.igx`, plus `.gz` and `.zip`).
    - ZIP with many IGCs? → one row per inner IGC.
    - Basic duplicate detection to flag repeats.
- **Manual import**
    - Paste a Drive link/ID or direct URL to an IGC/GZ/ZIP.
    - Or insert a **blank row** if you’re logging without a file.
- **Smart summaries**
    - Track length, straight-line distance, duration.
    - Max/min altitude, max climb/sink, max/avg groundspeed.
    - Auto sentence like: `3h 02m, Track 46.8 km, max alt 2,745 m at Bir`.
- **Location intelligence**
    - Reverse-geocodes launch & landing to nearest town, country, region.
    - Looks up closest paragliding **takeoff/landing** names from OpenStreetMap.
- **XC scoring**
    - Computes **XC distance**, **Flat triangle**, **FAI triangle**.
    - Shows **World points** and **National points** (closed-triangle bonus).
- **Flight analytics (modes)**
    - Classifies time in **Thermal / Soar / Glide / Sink**.
    - Thermal stats (count, average climb, best climb, longest).
    - Soaring stats (time, distance, passes, efficiency).
    - Glide stats (L/D distribution, mean groundspeed).
    - Sink exposure (time < −3 m/s, worst 5-s sink).
- **Gear-aware**
    - Auto-fills **Wing/Harness/Reserve 1/2** from the file or your last flight.
    - Each choice comes from your master lists (easy dropdowns).
    - Wing specs (glide ratio, trim, full-bar) are snapshotted per flight.
- **Friendly workflow**
    - New flights always insert at row 6 (newest first).
    - Status flag: OK / Needs review / Possible duplicate / Likely duplicate.
    - Recompute action for selected rows if you tweak thresholds later.

---

## How to use it (day-to-day)

### 1) Add your flights

You have three options from the **Flight Log** menu:

- **A) Watched folder (hands-off)**
    1. Put your new IGCs into the watched Drive folder.
    2. Each file (or inner file in a ZIP) becomes a new row at the top.
    3. Rows are marked **Needs review** so you can glance and confirm.
- **B) Add flight from IGC**
    1. Click **Add flight from IGC**.
    2. Paste a **Drive link/ID** or a **direct URL** to `.igc/.igx/.gz/.zip`.
    3. The sheet imports and fills the row for you.
- **C) Add blank flight row**
    1. Click **Add blank flight row** to log a flight without a file.
    2. Fill in the basics (date, duration, launch/landing, etc.).
    3. You can attach the file later by editing the IGC link fields and running **Recompute**.

> Tip: If your IGC doesn’t list the wing, the sheet copies your last flight’s gear so you only change it when needed.
> 

---

### 2) Review the new row

- **Auto Summary** gives a quick feel for the flight.
- **Flight Type** (dropdown) — choose one: *Free Fly, XC, Soaring, Comp, SIV / Maneuvers, Training, Other*.
- **Status**:
    - **Needs review** → skim the row; if correct, leave as is (or switch to OK).
    - **Possible/Likely duplicate** → compare with nearby rows; keep or merge as you prefer.

---

### 3) Check places & sites

- Launch/Landing show **Lat/Lon**, **Nearest Town**, **Country/Region**, plus the closest **PG site** name if found.
- If something looks off, you can still type your preferred site name in the cell.

---

### 4) XC & points

- See **XC Distance**, **Flat Triangle**, **FAI Triangle**, and **Points (World/National)**.
- The sheet automatically picks the **best** scoring result for “XC Flight Class” (Free / Flat / FAI) and notes if it’s **Closed**.

---

### 5) Flight analytics (modes)

- Mode time split: **Thermal, Soar, Glide, Sink** (minutes and %).
- Thermal metrics (count, avg climb, best, longest, total gain).
- Soaring metrics (time, distance, passes, efficiency).
- Glide quality (median/p90/best L/D; mean groundspeed).
- Sink exposure (< −3 m/s time; worst 5-s).

> These are computed from your track’s heading/vario and your wing’s glide ratio snapshot. If you later update wing specs, select the row(s) and Recompute.
> 

---

### 6) Add your notes & weather

- Use the **Weather** columns to record wind (dir/avg/gust) at launch/landing, cloud %, cloudbase/top of lift, temps, and any observations.
- **Personal notes**: “What went well”, “What to improve”, general notes, incident & airspace flags.
- **Photos**: paste a gallery URL (Drive/Photos) so future-you can find it.

---

### 7) Fixes & re-runs

- If you change thresholds, wing specs, or site radius later:
    - Select the rows → **Recompute selected flight(s)**.
- If an import missed a site/town due to a slow lookup:
    - Use **Recompute** on that row to retry.

## Quick FAQ

**Q: I imported a ZIP and only some tracks appeared—why?**

A: The sheet only processes files inside the ZIP that end with `.igc` or `.igx`. Non-IGC entries are ignored. Very large ZIPs may be partially processed (you’ll still get a note in the log).

**Q: It says “Likely duplicate.” What should I do?**

A: Compare the two rows (date, launch, duration). Keep your preferred one and delete the other—or keep both if they serve different purposes. The sheet won’t auto-merge.

**Q: My wing didn’t appear automatically.**

A: Some IGCs don’t include the glider name. The sheet copies your last flight’s gear to save time—use the dropdown to change it.

**Q: The triangle/points look odd.**

A: The sheet picks the best scoring option from your track. If you believe a triangle should score differently, check your track completeness (start/end), or select the row and **Recompute**.

## Glossary (short & sweet)

- **Track Length**: Total distance flown along the path (sums all tiny segments).
- **Straight Start→Finish**: Direct line distance from first to last point.
- **FAI Triangle**: Triangle where the shortest leg is ≥ 28% of the total perimeter.
- **World/National Points**: Standard XContest multipliers (World), plus optional closed-triangle bonus (National).
- **Modes**:
    - **Thermal**: Turning climb.
    - **Soar**: Ridge/soaring pattern, gentle turns, small altitude changes.
    - **Glide**: Straight flight near your wing’s expected L/D.
    - **Sink**: Stronger-than-expected descent or poor L/D.

---

Enjoy the logging—and the insights. If anything looks off (a site name, a weather note, a duplicate), edit the cell or run **Recompute**. The goal is fast capture first, tidy details later.

## 8) Dedupe & Import Log

`Import_Log` records: `When`, `FileId`, `OuterName`, `InnerName`, `Status`.

Dedupe keys:

- **File ID** (outer) and **content checksum** (inner IGC text).
- If seen before → skip.

Duplicate detection across Flights (to flag duplicates from different devices/paths):

- Score from:
    - **Start time proximity** (≤15 min; higher score if ≤5 min),
    - **Launch proximity** (≤500 m; higher score if ≤150 m),
    - **Duration similarity** (≤5%),
    - *(optional later)* track overlap %.
- Decision:
    - Score ≥ 0.80 → **Likely duplicate** (still create row; flag red).
    - 0.50–0.79 → **Possible duplicate** (amber).
    - < 0.50 → OK.

## 9) Parsing & metrics

### IGC parsing

- Read metadata: date (`HFDTE`), pilot (`HFPLT/HOPLT`), glider (`HFGTY/HOGTY`), registration (`HFGID/HOGID`), timezone notes.
- Parse `B` records into fixes: `ts`, `lat`, `lon`, `gAlt` (GNSS) or `pAlt` (pressure).

### Core computations

- **Track Length (km)**: sum haversine over downsampled fixes (1–2 s).
- **Straight Start→Finish (km)**.
- **Duration**: `end ts − start ts`.
- **Max/Min Alt**, **Max Ascent/Descent** (m/s), **Max/Avg GS (km/h)**.

### Launch & landing

- Takeoff: first fix; Landing: last fix (simple version).
- **Reverse-geocode** each to `Country`, `Admin1`, `Nearest Town` (provider from Lookups, default Nominatim).
- **OSM Overpass** query (radius from Lookups; default 3 km) for nearest paragliding **`takeoff/landing`** features; record **Site Name** for launch/landing.

## 10) Gear autofill & validation

- **Wing**: try from IGC header; if missing, **copy from previous flight (row 7)**; dropdown from `Equipment_Wings` first column.
- **Harness/Reserve 1/Reserve 2**: copy from previous row; dropdowns from their master tabs.
- Snapshot wing specs (`GlideRatio_LD`, `Trim_kmh`, `FullBar_kmh`) into hidden “(snap)” columns per flight.

---

## 11) Modes & analytics (XC-centric)

**Signals** (windowed; default 10 s):

- `vario_s` (smoothed climb m/s from alt deltas),
- `turn_rate_med` (°/s; median heading change),
- `L/D_obs` (window horizontal distance / vertical loss),
- `heading_reversals` (count over 30 s).

**Defaults (editable in Lookups):**

- **Thermal**: `vario_s ≥ +0.3` **and** `turn_rate_med ≥ 8`.
- **Soar**: `turn_rate_med ≤ 5` **and** `−0.2 ≤ vario_s ≤ +1.5` **and** `heading_reversals ≥ 2`.
- **Glide**: `turn_rate_med ≤ 5` **and** `vario_s ≤ +0.2` **and** `L/D_obs` within **±30%** of **GlideRatio_LD (snap)**.
- **Sink**: otherwise, if `vario_s ≤ −2.5` **or** `L/D_obs < 0.5 × GlideRatio_LD`.

**Hysteresis**: require ≥6 s stability before changing modes (ignore 1–2 sample blips).

**Outputs** (per §3G): time/distance/% in each mode; thermals count/avg/best/longest/gain; soaring time/distance/net gain/passes/mean leg/efficiency; glides L/D (median/p90/best) & mean GS; sink time < −3 m/s and worst 5 s sink.

## 12) XContest scoring

**Rules**

- Compute best **free distance** with up to 3 turnpoints along the ordered track (start + up to 3 TPs + finish).
- **Triangle** valid if closing gap ≤ **20%** of triangle perimeter.
- **FAI triangle** if shortest leg ≥ **28%** of perimeter.
- **World points multipliers**: Free=1.0×, Flat=1.2×, FAI=1.4×.
- **National points**: if triangle is **closed within** `NATIONAL_BONUS_WITHIN_PCT` (default 5%), multiply by `NATIONAL_BONUS_MULTIPLIER` (default 1.2). Always output both World & National points.

**Implementation notes**

- Downsample to ~1–2 s.
- Pruned search / heuristics for 0–3 TPs.
- Store: `XC Distance (km)`, `Flat Triangle (km)`, `FAI Triangle (km)`, `XContest Points (World)`, `XContest Points (National)`, `XC Flight Class` (Free/Flat/FAI), `Closed?` Y/N.

- `Place` priority: Launch Site (OSM) → Nearest Town → Country.
- Written once at import and on recompute.

    - This creates an Apps Script trigger to run every 5 minutes.
    - The script still **self-throttles** using `WATCH_PERIOD_MIN` from Lookups (e.g., 15 minutes), so it won’t over-scan.

**Option B (manually in Apps Script):**

- In the script editor, open **Triggers** (clock icon) → **Add Trigger**
    - Function: `scanWatchFolder_`
    - Event source: **Time-driven**
    - Select a schedule (e.g., every 5 minutes)
    - Save.

Now, whenever you drop IGCs (including ZIPs with multiple IGCs) into the watch folder, the sheet will create **one flight row per inner IGC**.

## 11) Quick troubleshooting

- **No new rows?**
    - Check `Lookups.WATCH_FOLDER_ID` (is it a valid folder ID?).
    - Verify the trigger exists (step 9).
    - Try **Flight Log → Scan Watch Folder now**.
- **Permissions error (DriveApp.getFileById)**
    - Re-run any menu action and **re-authorize** when prompted.
- **ZIP imported only some tracks**
    - Only `.igc`/`.igx` files inside the ZIP are processed. Very large ZIPs may be capped to keep within quotas.
- **Sites/Towns missing or odd**
    - Temporary map API hiccups happen; select the row and **Recompute selected flight(s)**.
