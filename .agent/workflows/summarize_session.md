---
description: End session routine: Sync project, update context, and create session report
---
1.  **Execute Sync Project**:
    -   Perform all steps in `sync_project.md`.
2.  **Update Context**:
    -   Read `Docs/Context.md`.
    -   Update high-level status, focus, and next steps in `Docs/Context.md`.
3.  **Archive Old Plans**:
    -   Move any existing `Plans/implementation_plan.md` or similar to `Plans/Archive/`.
4.  **Create Session Report**:
    -   **Reference**: See `Docs/Context.md` -> "Session Summary Reports" for naming and structure.
    -   **Location**: `Plans/SessionSummary/`.
    -   **Name**: `YYYY-MM-DD_SessionSummary.md`.
    -   **Content**:
        1.  **Metadata** (Date, Time, Goal).
        2.  **Key Discussions**.
        3.  **Decisions Made**.
        4.  **Work Completed**.
        5.  **Open Issues / Next Steps**.
        6.  **References**.
5.  **Notify User**:
    -   Confirm session summary creation and readiness to end session.
