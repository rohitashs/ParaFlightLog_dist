---
description: Start a new session by reading context, backlog, and summarizing the last session.
---

1.  **Read Core Context**:
    -   View `Docs/Context.md` to understand the project's "Ways of Working" and current status.

2.  **Read Documentation**:
    -   List the `Docs/` directory.
    -   View all other `.md` files in `Docs/` (e.g., `Technical_Specification.md`, `Features.md`, `Setup_Guide.md`) to build full context.

3.  **Understand Project Structure**:
    -   List the root directory and key subdirectories (`Code/`, `Plans/`) to understand the file layout.

4.  **Read Backlog**:
    -   View `Docs/Backlog.md` to understand current priorities, active tasks, and open bugs.
    -   // turbo
    -   Run `code Docs/Backlog.md` to open the file in the editor for the user.

5.  **Review Latest Session**:
    -   List `Plans/SessionSummary/` to find the most recent session summary file (by date).
    -   View the content of the latest session summary.

6.  **Summary Output**:
    -   Provide a brief conversation summary:
        -   **Where we left off**: Summarize the key outcomes of the last session.
        -   **Top Open Items**: List the highest priority items from `Docs/Backlog.md` (e.g., In Progress items, High Importance ToDos).
        -   **Next Steps**: Suggest the immediate next actions based on the context.
